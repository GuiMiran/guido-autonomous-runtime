# GUIDO Autonomous Runtime

Bounded operational prototypes for the GUIDO SDD ecosystem. The repository
name is not a claim of unrestricted autonomy or production readiness.

| Entry | Scope |
| --- | --- |
| [AGENTS.md](AGENTS.md) | Trusted agent navigation and local verification boundaries |
| [Planning control plane](autonomy/README.md) | Authenticated, planning-only service and approved repository context |
| [Evaluation adapter](evaluation/README.md) | Separate bounded candidate-evaluation boundary |
| [Change history](CHANGELOG.md) | Component changes and historical notes |
| [Shared governance hub](https://github.com/GuiMiran/spectra/tree/main/docs/ecosystem) | Ownership, version baselines and cross-repository traceability |

Read the narrower instructions before changing a subsystem. No model may
grant itself tools, modify source, merge or deploy through the planning API.
Merged changes are not proof of deployment, effective protection or response
quality. Approval and independent evidence remain separate requirements.
